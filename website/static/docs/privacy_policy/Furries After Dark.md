# Privacy Policy

Furries After Dark is a private Discord bot for the Discord server Furries After Dark (ID 1117341739431239770, The Guild), and is run by Voxel Fox Ltd, trading as Voxel Fox (UK company number 12467253).

## Why we collect and use data

Collecting some user data and processing user generated content (UGC) is necessary to ensuring the bot's functionality.

## What data is collected

The following data is collected and stored:

* **User IDs**

    There are many instances in which your user ID may be stored. The most notable which do not require you to interact directly with the bot, and ones you cannot opt out of, are in regard to levelling and when interactions are performed on you.

    Almost every other command that you run or that is applied to you will result in your user ID being stored - such as gaining or spending credits, leashing another user, opting out of interactions, and opening tickets.

* **Guild IDs**

    A guild ID is stored when running the settings commands for the bot.

* **Channel IDs**

    Channel IDs are stored when running relevant the settings commands for the bot.

    Channel IDs are also stored in combination with user IDs when a ticket is opened

* **Role IDs**

    Role IDs are stored when running relevant settings commands for the bot.

* **User Generated Content**

    A channel log - including a user ID, username, and message content for every message in the given channel - is stored when a ticket is closed.

## Where data is stored and secured

Data is stored in a password-protected and IP-whitelisted database. The server that the database is kept on is secure, and its hard drive is encrypted. This server is located in the EU.

## Where data is shared

Raw data is not shared with other entities. Much of the stored data is publicly accessible via the bot through various means. The mentioned UGC is only viewable by current moderators of The Server.

## Concerns

If you have any concerns about the usage of your data or wish to have some of it deleted, please [contact us](mailto:privacy@voxelfox.co.uk?subject=Privacy%20Policy%20Concern%20re%20Furries%20After%20Dark).
