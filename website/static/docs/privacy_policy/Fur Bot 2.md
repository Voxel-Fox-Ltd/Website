# Privacy Policy

Fur Bot 2 (The Bot) is a private Discord bot for the Discord server Furry Legion (ID 768195997662576681, The Guild) is run by Voxel Fox Ltd, trading as Voxel Fox (UK company number 12467253). 

The following describes the data stored by The Bot.

## Why we collect and use data

Collecting data is necessary in order to allow The Bot to run properly. Without storing some aspects of your user data, The Bot would not be able to function correctly.

## What data is collected

We collect the following: 

* **User IDs**

    * A user ID is collected when an account runs a moderation action (kick, ban, timeout, warn) - both the account that performed the action and the account that the action was performed against logged.
    * A user ID is collected when an account tagged as a staff member (ie an account in the guild with the staff role ID) sends a message, up to once per minute. The message contents are not stored.
    * A user ID is collected when an account gives or receives a daily gift from a user during one of the holiday events.
    * A user ID is collected when an account opts into a giveaway.
    * A user ID is collected when an account "purchases" a role from the server, collects credits, collects holiday currency, or runs the "daily" command.
    * A user ID is collected when an account makes progress on a quest.
    * A user ID is collected when an account performs a staff action (verification approval/denial, closing a modmail) - both the account that performed the action and the account that the action was performed against logged.

* **Channel IDs**

    * A channel ID is collected when a giveaway is started, in order to track the message that the giveaway is associated with.

* **Role IDs**

    * A role ID is collected and associated with a user ID when an account "purchases" a role from the server.

* **Message Content**

    * User message content is NOT stored other than via the use of slash commands or interactions. The Bot uses the "message content" Discord intent in order to read user messages, which it uses to run commands.

## Where data is stored and secured

Data that we collect is stored in a database. This database is not accessible by other entities. The server that the database is kept on is secure, and its hard drive is encrypted. The database is physically located within the EU.

## Where data is shared

Raw data is not shared with other entities.
